Output 1 · LED

Long leg through a 330Ω resistor to GPIO 18. Short leg to ground.

PWMLED gives you brightness, not just on and off.

[Fritzing diagram: LED + resistor on GPIO 18]

from gpiozero import PWMLED
led = PWMLED(18)

async def handler(ws):  # replaces the old handler
    clients.add(ws)
    async for msg in ws:
        if msg == "led:toggle": led.toggle()
        elif msg.startswith("glow:"): led.value = float(msg[5:])
    clients.discard(ws)

// in setup():
createButton("Toggle LED").mousePressed(() => ws.send("led:toggle"));
const glow = createSlider(0, 1, 0, 0.01);
glow.input(() => ws.send("glow:" + glow.value()));

The new handler listens for messages until the browser disconnects, then tidies up. Never skip the resistor — without it the LED (and possibly the pin) burns out. Once it works, swap the HTML button for anything in the sketch: a click on a shape, a timer, or the proximity value.
