How the pieces talk

01

Input

Button, knob or sensor

02

GPIO

The Pi’s header pins

03

Bridge

Python + gpiozero, sends WebSocket messages

04

Sketch

p5.js in Chromium

05

Output

Screen or projector

Everything runs on the Pi. A browser can’t read pins, so the bridge translates presses into messages.

This is the mental model for the whole workshop. Each hands-on part builds one box. The bridge (highlighted) is the bit most people haven’t seen before.
