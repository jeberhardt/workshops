Going full screen

01

Fill the window

Size the canvas to the screen and hide the cursor. In style.css: body { margin: 0; overflow: hidden; }

function setup() {
  createCanvas(windowWidth, windowHeight);
  noCursor();
}
function windowResized() {
  resizeCanvas(windowWidth, windowHeight);
}

02

Hide the browser

Just testing? Press F11. For a show, launch in kiosk mode: no tabs, no address bar, no pop-ups.

chromium-browser --kiosk --noerrdialogs \
  --disable-infobars http://localhost:8000

03

Keep it awake

Stop the screen going black after ten idle minutes.

sudo raspi-config
# Display Options, then Screen Blanking, then No

To quit kiosk mode while testing, press Alt+F4 (or Ctrl+W). On newer Raspberry Pi OS releases the command is chromium instead of chromium-browser. p5’s fullscreen() needs a click from the viewer first, so it isn’t useful for an unattended piece; kiosk mode is. To start it at boot, add the same command to the desktop’s autostart file (on current Raspberry Pi OS with labwc: ~/.config/labwc/autostart) — covered again on the install slide. [Check the default idle time and the exact menu wording on your workshop OS image.]
