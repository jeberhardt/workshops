Smoothing in code

let target = 0, near = 0;

ws.onmessage = (e) => {
  if (e.data.startsWith("near:"))
    target = float(e.data.slice(5));
};

function draw() {
  // move 10% of the way there, every frame
  near = lerp(near, target, 0.1);
  // ...draw with near, never target
}

Store the latest reading as a target. Ease toward it in draw(), so motion stays smooth even when messages arrive unevenly.

lerp (start here)

One line. Tune the amount between 0.02 and 0.5.

Moving average

Average the last N readings. Easy to reason about.

Median

Middle of the last 5. Throws out single spikes.

Dead zone

Ignore tiny changes, so an empty room stays still.

Have everyone try 0.5, 0.1 and 0.02 on their proximity sketch and feel the difference. Techniques stack: a median to kill spikes, then lerp for calm, then a dead zone for stillness. The same pattern works for the slider. lerp per frame depends on frame rate; that’s fine for a fixed installation.
