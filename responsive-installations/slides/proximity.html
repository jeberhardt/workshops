Input 3 · Proximity

Now the input is the audience: how close someone is, many times a second.

HC-SR04: VCC to 5V, Trig to GPIO 23, GND to ground. Echo sends 5V, so it reaches GPIO 24 through a 1kΩ + 2kΩ voltage divider.

Run it raw first and watch it shimmer. That’s the problem the next two slides fix.

[Fritzing diagram: HC-SR04 + voltage divider]

from gpiozero import DistanceSensor
sensor = DistanceSensor(echo=24, trigger=23, max_distance=2)

# inside stream(), next to the slider:
near = 1 - sensor.distance / 2  # 0 = 2 m away, 1 = touching
websockets.broadcast(clients, f"near:{near:.3f}")

let near = 0;  // 0 = nobody, 1 = right up close
ws.onmessage = (e) => {
  if (e.data.startsWith("near:"))
    near = float(e.data.slice(5));
};

// in draw(): closer means brighter and bigger
background(0, 0, near * 100);
circle(width / 2, height / 2, near * 900);

The Python block runs inside the same stream() loop as the slider. Sending “near” as 0–1 keeps the p5 side identical whatever sensor you use. sensor.distance is in metres, capped at max_distance. The voltage divider is not optional: 5V on a GPIO pin can damage the Pi. gpiozero already averages a few readings internally, but the output still jitters and spikes, which sets up the smoothing slides. For installations: several HC-SR04s pointing the same way can hear each other’s pings, and soft clothing absorbs sound, so test with real people.
