Output 1 · NeoPixels

Three NeoPixels on one data wire: 5V, ground, and DIN through a 330Ω resistor and a logic level converter to GPIO 10 (pin 19).

Each pixel can be any colour. The SPI library drives them the same way on every Pi, without sudo.

[Fritzing diagram: 3 NeoPixels + resistor on GPIO 10]

import board, json, neopixel_spi
pixels = neopixel_spi.NeoPixel_SPI(board.SPI(), 3, brightness=0.3)

async def handler(ws): # replaces the old handler
    clients.add(ws)
    async for msg in ws:
        data = json.loads(msg)
        if "pixels" in data:
            pixels.fill(tuple(data["pixels"]))
    clients.discard(ws)

// in setup():
createButton("Lights on").mousePressed(() =>
  ws.send(JSON.stringify({ pixels: [255, 120, 0] })));
createButton("Lights off").mousePressed(() =>
  ws.send(JSON.stringify({ pixels: [0, 0, 0] })));

The new handler listens for messages until the browser disconnects, then tidies up. Each message is JSON: a name and its values in one piece of text, the same format the Outputs step sends. [255, 120, 0] is red, green, blue, 0–255, like fill(). brightness=0.3 because full brightness is dazzling up close and draws more power. One pixel at a time works too: pixels[0] = (255, 0, 0). The pixels expect 5V data and the Pi sends 3.3V: the converter lifts it. A few pixels often work without it, but a long strip needs it, so build the habit now. The 330Ω resistor protects the first pixel’s data pin. Once it works, send the circle’s colour instead, or tie the colour to the proximity value.
