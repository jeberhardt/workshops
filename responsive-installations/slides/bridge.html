Part 3 · Bridge to the browser

The bridge watches the pin and broadcasts “press” to every open browser.

Save it as bridge.py and leave it running:

python3 bridge.py

import asyncio, websockets
from gpiozero import Button

button = Button(17)
clients = set()

async def handler(ws):
    clients.add(ws)
    await ws.wait_closed()
    clients.discard(ws)

async def main():
    loop = asyncio.get_running_loop()
    send = lambda: websockets.broadcast(clients, "press")
    button.when_pressed = lambda: loop.call_soon_threadsafe(send)
    async with websockets.serve(handler, "localhost", 8765):
        await asyncio.Future()

asyncio.run(main())

gpiozero calls when_pressed from its own thread, so call_soon_threadsafe hands the message back to the asyncio loop. Test this script on the workshop Pis beforehand. To test from a laptop on the same network, change "localhost" to "0.0.0.0".
