Level 3

Light sensor

A number from 0 to 1 about the space

The input becomes the room · needs an ADS1115 chip

Each level sends richer data: a single event, then a continuous value the audience controls by coming closer, then a continuous value from the room itself: daylight, the house lights, a shadow passing over. The light sensor (LDR) is analog and the Pi has no analog inputs, so it reads through the ADS1115, as wired on the light sensor slide. The bars hint at how much information each one carries.
