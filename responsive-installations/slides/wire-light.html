Wire a light sensor

ADS1115 to 3.3V, ground, SDA (pin 3) and SCL (pin 5)

Light sensor from 3.3V to A0, 10kΩ from A0 to ground

Turn on I2C first: sudo raspi-config, then Interface Options, then I2C.

import time, board
import adafruit_ads1x15.ads1115 as ADS
from adafruit_ads1x15.analog_in import AnalogIn

ads = ADS.ADS1115(board.I2C())
light = AnalogIn(ads, ADS.P0)
while True:
    print(f"{light.voltage:.2f} V")
    time.sleep(0.1)

The Pi has no analog inputs, so the ADS1115 converts the light sensor's voltage into a number and sends it over I2C. The photoresistor and the 10kΩ resistor form a voltage divider: more light means lower resistance, so the voltage at A0 rises. Cover the sensor with your hand and the reading should drop. In the diagram: red is 3.3V, black is ground (from header pin 39, the bottom GND pin, which keeps it clear of the other wires; every GND pin on the Pi is connected, so any of them works), yellow is SDA, blue is SCL, and orange carries the light reading to A0. Fritzing has no ADS1115 part, so the diagram uses a labelled stand-in. Beside it is a photo of the actual blue breakout, with each pin name lined up with its pin, so people can match the diagram to the board in their hand. Install the library first: pip install adafruit-circuitpython-ads1x15. Run i2cdetect -y 1 to check the board shows up at address 48. [Check the import lines against the library version on the workshop image; newer releases changed how channels are named.]
