Part 1 · Set up the Pi

01

Flash Raspberry Pi OS with Raspberry Pi Imager

Set Wi-Fi, a username and SSH in the settings before you write the card.

02

Boot, then update

sudo apt update && sudo apt full-upgrade

03

Install the bridge’s one dependency

sudo apt install python3-websockets

04

Serve your sketch folder, then open localhost:8000 in Chromium

python3 -m http.server 8000

To save time, consider pre-flashing cards. gpiozero ships with Raspberry Pi OS, so websockets is the only install. Have a known-good sketch folder ready (index.html + sketch.js) for people to copy.
