Sensor → screen → sound.

1 · An input moves something. Walk towards the distance sensor and the shape slides across the screen.

2 · Something happens. The shape reaches the other side of the screen.

3 · The Pi answers. The sketch sends a message back, and the buzzer goes off or the NeoPixels light up.

// Start from the Real hardware step.
let beeped = false; // at the top

// in draw(), after x is worked out:
if (x > 0.8 && !beeped) {
  sendToHardware({ beep: { hz: 880, ms: 300 } });
  beeped = true; // only once
}
if (x < 0.5) {
  beeped = false; // back again: ready
}

Without beeped, the sketch would send a beep 60 times a second for as long as the shape stays on the right. The gap between 0.8 and 0.5 stops it from beeping over and over when someone stands right at the edge. Try your own versions: a different input (the button, the light sensor), a different event (the shape gets very small, the room goes dark), or a different output ({ pixels: [255, 0, 0] } turns the NeoPixels red).
