Use a different pin

1. Move the wire from GPIO 17 to any free GPIO pin. The ground wire stays where it is.

2. Change the number in the code to match. Use the GPIO number, not the pin’s position on the header.

b = Button(27)    # was Button(17)

# or count pins along the header:
b = Button("BOARD13")

Already in use today: GPIO 2 and 3 (light sensor), 10 (LEDs), 13 (buzzer), 23 and 24 (proximity sensor).

The Pi has two numbering systems, and mixing them up is the most common mistake. The GPIO number is the chip's name for the pin, and it's what gpiozero expects by default. The header pin is its physical position, counted from pin 1 at the corner. GPIO 17 sits at header pin 11, for example. gpiozero also accepts "BOARD11"-style names if counting along the header is easier. Change the number everywhere it appears: in the test script and in bridge.py. For a second button, wire it to another free pin and add a second Button with its own number. The pins in the table are free on every Pi since the Pi 2 and aren't used by today's other parts. Avoid GPIO 2 and 3 for buttons even when they look free: they have built-in pull-up resistors for I2C.
